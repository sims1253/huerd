# Print Method for huerd_palette Objects

Custom print method for color palettes generated by `huerd`. Displays
the colors and a brief summary of quality metrics if available.

## Usage

``` r
# S3 method for class 'huerd_palette'
print(x, ...)
```

## Arguments

- x:

  An object of class `huerd_palette` (a character vector of hex colors).

- ...:

  Additional arguments (not used).
